Overview

What Does EIAMS Do?

A centralised platform for organisations to track physical inventory, manage fixed assets, control stock levels, and enforce role-based access — all in one system.

🗃️

Inventory Management

Track items, categories, suppliers, locations. Barcode & QR code generation. Low-stock alerts.

🖥️

Asset Lifecycle

Register assets, assign to users, transfer between locations, schedule maintenance, record disposals.

📊

Stock Control

Log every stock movement with full audit trail. Automatic low-stock alerts. PDF & Excel exports.

👥

User & Role Management

4 system roles with fine-grained access control. Admin can manage users, reset passwords, change roles.

📈

KPI Dashboard

Real-time charts for stock in/out, asset status, category breakdown. Warranty expiry warnings.

🔔

Notifications

In-app notification system for system events. Bilingual support: English & Khmer (ខ្មែរ).

Access Control

4 System Roles

Every user is assigned exactly one role. Role-based decorators enforce access on every view.

👑

Super Admin

Unrestricted access to everything. Manages all users including other Admins. Only role that can delete Admin accounts or change Admin passwords.

🛡️

Admin

Full CRUD on inventory, assets, stock. Manages Staff & Manager accounts. Cannot touch Super Admin accounts.

📋

Manager

Creates & edits inventory items, suppliers. Approves/rejects asset transfers. Cannot manage users or delete master data.

👤

Staff

Read-only access to inventory & assets. Can request asset transfers. Can update own profile and password only.

  • Assign or change any user's role

Everyday system user. Read access to inventory and assets. Can request asset transfers and manage their own account only.

Business Rules

Asset cannot be transferred to the same location. Blocked statuses (Maintenance / Disposed / Lost) cannot be transferred.

Auto-Generated

Transfer number format: TRF-YYYY-NNNNNN. Asset location updates only on Completed — not on Approved.

Audit Trail

Every status change creates an immutable TransferHistory record with actor, timestamp, and notes.
